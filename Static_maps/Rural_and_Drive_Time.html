Rural and Drive Time Map

How it was made:

First I imported the the updated park csv file into ArcGisPro.

I then used the ‘create points from table’ function and selected XY table to point.

I then imported USA Major cities from ESRI.

After importing use the Select by Attribute function to create a new query.

Apply and then left click on the layer and go to selection and then select ‘make layer from selection’

Next I had to edit the parks table and I could not use the select by attribute feature for some odd bug so I manually deleted everything and cleaned it to a new table called North East Parks

I then when to Generate Drive Time Trade Areas and created Rural drive times of 10 15 and 30 minutes

For this example I wanted to zone in on NY, PA. MA, NJ, and MA. So I made a second selection on the Parks points and then ran two different time Trades.

1. For Rural driving in Miles

2. For Drive time.

I then changed the symbology and added state boundaries and changed their symoblogy to make state’s boundaries stand out
from one another.
